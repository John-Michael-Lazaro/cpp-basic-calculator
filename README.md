# cpp-basic-calculator

My second C++ project. A simple calculator that takes two numbers and displays their sum, difference, product, and quotient.

## What I Learned
- Variables and data types
- User input and output
- Arithmetic operators
- `if/else` statements
- Basic input validation
- Formatting decimals with `iomanip`

## Built With
- C++

## Future Improvements
- Let users choose an operation
- Allow multiple calculations without restarting the program
